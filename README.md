\# AI Interview Analyzer



An AI-powered interview analysis application that evaluates a candidate's visual behavior, voice response, and answer quality during a mock interview.



\## Features



\- 🎥 Real-time webcam analysis

\- 👤 Face detection

\- 👀 Eye detection

\- 👁️ Approximate eye-contact analysis

\- 🧍 Head-position detection

\- 📊 Visual performance score

\- 🎙️ Voice recording

\- 📝 Automatic speech-to-text

\- 🚫 Filler-word detection

\- 🎤 Voice performance score

\- 💡 Personalized interview feedback

\- 🏆 Overall interview score

\- 📄 Detailed interview report

\- 📥 PDF report download



\## Technologies Used



\- Python

\- Streamlit

\- OpenCV

\- Streamlit-WebRTC

\- SpeechRecognition

\- ReportLab



\## How It Works



1\. Select an interview question.

2\. Start the webcam.

3\. The system analyzes face, eyes, eye contact, and head position.

4\. Record your answer using the microphone.

5\. The system converts speech into text.

6\. The answer is analyzed for word count and filler words.

7\. Visual, voice, and answer scores are calculated.

8\. Generate a final interview report.

9\. Download the report as a PDF.
